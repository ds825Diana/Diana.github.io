IMPERIAL COLLEGE LONDON · 2025–2026

从自然语言查询，到真实机器人导航。From a natural-language query to supervised real-robot navigation.

构建连接开放词汇语义理解、三维空间记忆与二维 ROS 导航的完整闭环。系统将自然语言扩展为视觉检索词，从场景图定位对象，经人工确认后生成经过几何验证的自由空间目标，并发送至 SCOUT 2.0 执行。Built an end-to-end pipeline connecting open-vocabulary semantics, 3D spatial memory and 2D ROS navigation. A query is grounded to a scene-graph node, converted into a validated free-space goal and executed on SCOUT 2.0.

与具身智能的关系WHY IT MATTERS FOR EMBODIED AI

项目解决“语言意图如何落到物理空间行动”这一关键接口：把感知、语义推理、空间表示、规划和实机执行组织成可验证的系统，而不只是单独优化一个模型。The work grounds language intent into physical action by orchestrating perception, reasoning, spatial representation, planning and execution as one testable system.
